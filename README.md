## 我自己修掉的三处错误（这段比结果更能说明问题）

**一、相干公式恒等于 1**
初版脚本写的是 `coh = |W1·conj(W3)|² / (|W1|²·|W3|²)`，分子分母在数学上恒等，所以算出来整张图都是 1.000，跟数据完全无关。
改用 Welch 平均的幅值平方相干（`scipy.signal.coherence`, nperseg=256）后才有真实值：P2–P4 在 97.2 Hz 为 **0.831**。

**二、HHT 分解退化**
初版 `emd.sift.sift(x)` 没限制 IMF 数量，分解出 **720 个 IMF**（正好等于信号长度），边际谱没有任何物理意义；原图上那句「故障主频 97.22 Hz」是人工标注上去的，不是算出来的。
我判定该方法在这段数据上不可用，**没有把它写进任何结论**（退化检测逻辑保留在 `01-pressure-pulsation/analyze.py` 里）。

**三、轴承脚本的转速量纲写错**
初版 `OMEGA = 0.025`（≈ 0.24 r/min），算出承载量只有 0.19 N——R = 50 mm 的轴承载 0.19 N 在物理上不成立。按 1500 r/min 工况改正后是 0.572 MPa / 1.22 kN。

## 怎么自己跑一遍

需要 python3，以及 `numpy pandas scipy matplotlib`（跑 HHT 分支还需要 `emd`，不装也能跑，脚本会自动跳过）。

```bash
cd 01-pressure-pulsation && python analyze.py
# → figures/coherence.png，并在终端打印四组测点对的相干值与主频

cd 02-bearing-simulation && python bearing_pressure_analysis.py
# → bearing_pressure_analysis.png + bearing_pressure_2d.csv，并打印迭代次数与承载量
```

两个脚本都只读仓库内的数据、只写自己的目录，不依赖我本机的任何路径。
