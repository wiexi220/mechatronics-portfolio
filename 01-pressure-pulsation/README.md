# 离心泵压力脉动信号分析与故障诊断

机电设备健康检测实训 · 2026.06 · Python

## 数据从哪来

四测点压力脉动信号，**由实训指导教师提供**（不是我采集的）：

| 项 | 值 |
|---|---|
| 测点 | P1（泵进口）、P2、P3（叶轮出口）、P4 |
| 采样间隔 | 0.0001 s → 采样频率 **10 kHz** |
| 点数 | 720 |
| 记录时长 | 0.0719 s |
| 频率分辨率 | fs/N ≈ **13.89 Hz** |
| 工况 | 正常态 / 故障态（叶轮损伤）各一组，同一测点布置 |

原始数据在 `data/pressure_4points.csv`（从实训下发的 xlsx 原样导出，未做任何平滑或重采样）。

## 我做了什么

1. 四个测点分别去均值后做时域统计；
2. 对 P1、P3 做 FFT，定位主频并对照叶片通过频率（BPF）；
3. 用 **Welch 平均的幅值平方相干**（`scipy.signal.coherence`, nperseg=256）逐对计算四个测点的相干谱，看故障频率上的能量来自哪两个测点之间；
4. 尝试 HHT（EMD + Hilbert 边际谱），发现分解退化后**判定该方法不适用并放弃**。

## 结果

FFT 主频：

| 测点 | 主频 | 幅值 | 说明 |
|---|---|---|---|
| P1（进口） | **277.78 Hz** | 1287.8 Pa | 对应叶片通过频率 BPF |
| P3（叶轮出口） | **97.22 Hz** | 654.5 Pa | 故障特征频率 |

幅值平方相干（97.2 Hz 与 277.8 Hz 处）：

| 测点对 | 97.2 Hz | 277.8 Hz |
|---|---|---|
| P1（进口）– P3（叶轮出口） | 0.160 | 0.140 |
| **P2 – P4** | **0.831** | 0.723 |
| P1（进口）– P2 | 0.274 | 0.888 |
| P3（叶轮出口）– P4 | 0.110 | 0.099 |

时域结论（见 `../04-training-report/`）：故障态脉动峰峰值 **12217.42 Pa**，约为正常态的 **3.7 倍**；故障态平均压力 123287.56 Pa，脉动范围 −7780.5 ~ 4436.9 Pa。

**结论：故障能量集中在叶轮出口区域**（P2–P4 在故障特征频率 97.2 Hz 上高度相干，而进口侧 P1 与叶轮出口 P3 几乎不相干）。该结论已由指导教师核算确认。

## 两处方法学修正（相对 `legacy_wavelet_buggy.py`）

**1. 相干公式恒等于 1 —— 原脚本无法给出任何结论**

原写法：

```python
coh = np.abs(cwt1 * np.conj(cwt3))**2 / (np.abs(cwt1)**2 * np.abs(cwt3)**2)   # 恒等于 1
```

分子与分母在数学上完全恒等，因此结果与数据无关，整张图都是 1.000。这是"看起来有图、其实什么都没算"的典型错误。
修正后改用 `scipy.signal.coherence`，得到上表里那些有区分度的值。

**2. HHT 分解退化，边际谱不可用**

`emd.sift.sift(x)` 未限制 IMF 数量时，分解出 **720 个 IMF**（= 信号长度 720），边际谱无物理意义；原图上「故障主频 97.22 Hz」是 `annotate` 人工标注的，不是计算结果。
`analyze.py` 里保留了退化检测：一旦 IMF 数接近信号长度，直接判定该方法在该数据上不可用，**不输出该图**。作为对照，原图仍留档在 `figures/hht_degenerate_INVALID.png`（文件名已标明无效）。
