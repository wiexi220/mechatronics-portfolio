## SCL 源码：`scl/motor_start_stop_fault_latch.txt`

电机启停控制 + 故障保护，逻辑是三个状态位加互锁：

- 热继电器动作 → `M_Fault` 置位并停机（**锁存**，防止故障未排除就自动重启）
- 只有按复位按钮才能清除 `M_Fault`
- 启动条件：`无故障 AND 启动按钮 AND 未按停止`
- 输出：接触器 / 运行绿灯 / 故障红灯

变量按博途的习惯映射到 I0.0–I0.3、Q0.0–Q0.2。
