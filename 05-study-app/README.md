# 「升学助手」备考 App（自研工具）

独立仓库：<https://github.com/wiexi220/weix> · MIT License · 纯前端 PWA

这个目录不再重复放源码，源码与使用说明都在上面那个仓库里。这里只说明它是什么、以及它和机电方向的关系。

## 是什么

我在备考重庆专升本（高等数学 / 计算机 / 大学英语）时自己写的离线备考工具，原因很具体：市面上的 App 广告多、数学公式排版差、断网就用不了，而教室和图书馆经常是弱网环境。

自己做的时候按需求拆成 4 个模块，逐个实现、逐个验收：

| 模块 | 说明 |
|---|---|
| 每日打卡 | 三科打卡 + 错题达标记录 |
| 错题本 | 按知识点归集，支持重做 |
| 每日一题 | 按学科轮换推送 |
| 工具 | 番茄钟、单词短语、公式速查等 |

题库累计约 2000 题，覆盖三科。

## 技术上值得说的三点

1. **KaTeX 字体子集化** —— 数学公式渲染完整字体包体积过大，做子集化后只保留用到的字形，首屏资源压到约 1.5 MB
2. **Service Worker 离线可用** —— 全部资源本地缓存，断网照常刷题（这是最初的痛点）
3. **localStorage 数据备份** —— 打卡与错题数据可导出/导入，换设备不丢

另外配了一个桌面悬浮计时器（Windows 端）配合番茄钟使用。

## 和机电方向的关系

严格说，这个项目和设备维修 / 调试岗没有直接关系。放进来是因为它是我**从定需求、拆模块、到持续迭代维护了一年**的东西，而且踩的都是真实工程问题（体积、离线、数据持久化）。如果需要，它也能说明我能自己读懂一门技术的边界在哪。
